# 濟州島自駕旅行網站：使用說明

整個網站就是**一個檔案：`index.html`**。不用安裝任何東西，雙擊就能在瀏覽器打開。

## 一、預覽
- 電腦：直接雙擊 `index.html`。
- 手機：用「免費發布」（下面）拿到網址再開。
- 即時天氣、內嵌地圖、Google 字型需要連網；用 Claude 內建預覽時外部連線會被擋，天氣會顯示「連不到」和查詢連結（不會顯示假資料）。**發布到下面的網址後就能正常顯示。**

## 二、免費發布成網址（挑一個，約 2 分鐘）

### 方法 A：Netlify Drop（最簡單，不用註冊也能試）
1. 開 https://app.netlify.com/drop
2. 把 `index.html` 放進一個資料夾（資料夾名稱隨意），把**整個資料夾**拖進網頁。
3. 幾秒後會給你一個網址，傳給旅伴即可。想要固定網址就註冊免費帳號，並認領這個網站。

### 方法 B：GitHub Pages（網址最穩定）
1. 註冊 GitHub → 右上角「＋」→ New repository，名稱例如 `jeju-trip`，選 Public，建立。
2. 點「uploading an existing file」，上傳 `index.html`，按 Commit。
3. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`，Save。
4. 約 1 分鐘後網址是 `https://你的帳號.github.io/jeju-trip/`。

> 之後要更新：重新上傳同名的 `index.html` 覆蓋即可。

## 三、重要：資料存在「各自的手機」
預算、清單、備註、照片都存在**每個人自己的瀏覽器**裡。重新整理、關掉再開都會保留，但不會自動同步給旅伴。
- 想把預算／清單帶到另一支手機：到「預算」頁最下面按「複製備份文字」，傳給對方，對方按「貼上匯入」。
- 照片不在備份範圍內（檔案太大），每個人各自上傳。
- 換瀏覽器、無痕模式、清除網站資料，都會讓資料消失。

## 四、怎麼修改

### 修改行程、餐廳、清單預設內容
用「記事本」（Windows）或「文字編輯」（Mac，請選純文字格式）打開 `index.html`，搜尋 `修改區`（Ctrl/⌘ + F），就會看到一大段純文字資料，改**引號 `'...'` 裡面的字**就好。

| 想改 | 搜尋這個字 | 怎麼改 |
|---|---|---|
| 團名、日期、簡介 | `groupName` | 改引號內文字 |
| 航班、住宿時間 | `flights` / `hotels` | 改 `dep`、`checkIn` 等 |
| 某天的景點 | `days:` | 每個 `{ id: 'd1b', ... }` 就是一個景點；`name`＝名稱、`desc`＝簡介、`addr`＝地址、`stay`＝停留時間、`q`＝地圖搜尋字（用韓文最準） |
| 景點之間車程 | `drive:` | 改 `t:`（例如 `'約 30 分'`） |
| 新增景點 | 複製一整組 `{ ... },` 貼在想要的順序，`id` 要和別的不同 |
| 餐廳 | `restaurants:` | 改 `hours`（營業時間）、`closed`（公休）、`price`、`dishes`；查到後把「待確認」改成實際內容 |
| 清單預設 | `checklist:` | 每組的 `items` 裡新增或刪除項目 |
| 待確認事項 | `flags:` | 確認完的可以直接刪掉整組，或在網站上勾選 |

注意：不要刪掉逗號、引號、`{ }` 或 `[ ]`。改壞了就用備份還原。

### 不用改程式就能做的事（直接在網站裡）
- **指定景點**：Day 1 的「彩虹海岸道路」「西岸景點」、Day 2 的韓服店、Day 4 的還車地點，卡片上有輸入框，填入名稱後會自動產生 Google／NAVER 連結。
- **換照片**：每個景點／餐廳卡片的「換成我的照片／加上照片」；首頁左上角可更換主視覺；「相簿」頁可依 DAY 1–4 上傳與分類。
- **預算**：匯率、付款人名字、各項預算、新增／修改／刪除支出，都在「預算」頁。

## 五、關於資料的誠實說明
- 行程、時間、住宿、航班以你的 PDF 為準，沒有更動。
- 營業時間、公休、價格若查不到，一律標「待確認」；有來源的附連結。價格多為舊資料，請以現場為準。
- 景點之間的車程是粗估，請以 NAVER Map／車載導航為準。
- 景點與餐廳的實景照片我無法從網路取得，目前用你簡報圖的水彩插畫與預留的照片位置，出發前後自行上傳即可。

## 第二版更新說明

**字體**：內文 = 源石黑體（找不到時用同源的思源黑體）；手寫字 = 辰宇落雁體 →（粉圓 Huninn、M PLUS Rounded 1c 為備用圓體）。這兩套字體不能打包進預覽版，所以：
- 裝置已安裝該字體時會直接使用；
- 想讓所有人都看到：把字體檔（.woff2）放在網站資料夾，在 `src/style.css`（或 index.html 的 `<style>`）最上面加：
  `@font-face{font-family:'GenSekiGothic TW';src:url('GenSekiGothic-TW-R.woff2') format('woff2');}`
  `@font-face{font-family:'ChenYuluoyan-Thin';src:url('ChenYuluoyan-Thin.woff2') format('woff2');}`
  （請確認字體授權允許網站嵌入）

**地圖**：每日頁改為「濟州島示意地圖」（位置是估的大概位置，非導航）＋ Google／NAVER 按鈕；嵌入式 Google 地圖收在可展開區塊。**天氣**：即時預報需要網站連外，預覽環境會被擋；發布到 Netlify／GitHub Pages 後才會顯示，沒載到時改顯示 11 月氣候參考與官方連結（不放假資料）。
**匯率**：1 TWD = 40.69 KRW，可在預算頁修改。**清單**：項目、分類都可自己新增／修改／刪除，也可還原預設。
**行程備註**：每個住宿站點都標示入住／退房截止；Day 1 的 Hugely 移到機場後、晚上為「落火咖啡廳」（店名地址待你補）；Day 3 加了牛島船班、停航、租車上島與電動摩托車證件備註。

## 上傳到 GitHub Pages（免費）

1. 登入 GitHub → 右上角 **+** → **New repository**，名稱例如 `jeju-trip`，選 **Public**，按 Create。
2. 在新 repo 頁面按 **uploading an existing file**，把這包檔案（`index.html`、`.nojekyll`、`README.md`，也可連 `src/` 一起）拖進去，按 **Commit changes**。
3. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
4. 約 1–2 分鐘後，網址是 `https://你的帳號.github.io/jeju-trip/`。手機用這個網址開，天氣與地圖才會正常載入。
5. 之後要改內容：改 `src/data.js` 後執行 `python3 build.py` 會重新產生 `index.html`；或直接用 GitHub 網頁編輯 `index.html` 再 Commit。

> 提醒：打勾、預算、清單修改與照片都存在每個人自己的手機瀏覽器裡，不會同步給其他人。
